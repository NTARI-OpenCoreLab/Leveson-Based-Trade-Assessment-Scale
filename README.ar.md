# مقياس تقييم التبادل التجاري المبني على منهج Leveson (LBTAS)

نظام تصنيف للتجارة الرقمية يستند إلى منهجية Nancy Leveson لتقييم برمجيات الطائرات، مع معايير تقييم ثنائية الاتجاه.

## نظرة عامة

يُطبِّق مقياس تقييم التبادل التجاري المبني على منهج Leveson (LBTAS) منهجية نانسي ليفسون (Nancy Leveson) لتقييم برمجيات الطائرات، والتي طُوِّرت أصلًا لتطبيقات الفضاء الجوي، بعد تكييفها لسياقات التجارة الرقمية والتقييم الاقتصادي. يوفّر LBTAS إطارًا لجمع بيانات جودة المعاملات باستخدام مقياس من ست درجات.

## مشكلة أنظمة التصنيف التقليدية

لا توفّر أنظمة النجوم الخمس بيانات تحفّز المنتج على التحسين. فقد طوّرت شركة Forbes Travel Guide (المعروفة سابقًا باسم Mobil Travel Guide) نظام النجوم الخمس في عام 1958 للإعلان عن جودة الفنادق على طول الطرق السريعة بين الولايات الأمريكية. وقد صُمِّم كنظام تواصل أحادي الاتجاه موجّه للسفر على الطرق السريعة، لا للتجارة الرقمية.

**القيود:**
- التصنيفات تقدّم قيمة محدودة في سياقات التجارة الإلكترونية
- مديرو العلاقات العامة يضعون حواجز أمام تغيير السياسات
- درجة التفصيل لا تكفي لاستيعاب تعقيد المعاملات
- التقييم أحادي الاتجاه يتجاهل مسؤولية المستهلك
- نقص البيانات يفرض الاعتماد على أقسام التعليقات

## لماذا منهج Leveson؟

يعود أصل نظام Leveson إلى تطوير برمجيات الطائرات، حيث تؤدّي أعطال النظام إلى خسائر في الأرواح أو إلى إهدار استثمارات البحث والتطوير. وتتميّز هذه المنهجية بأنها:

- تستخدم مقياسًا من ست درجات (من +4 إلى -1) مع تعريفات لكل فئة
- تُكثِّف المعنى داخل كل مستوى من مستويات التصنيف
- تُقلّل الاعتماد على أقسام التعليقات كمصدر للبيانات
- تُتيح التقييم ثنائي الاتجاه (للمنتج والمستهلك على حدٍّ سواء)
- تدعم دورات التحسين القائمة على البيانات

## تعريفات المقياس

### +4 **الإبهاج**

التفاعل يستبق تطوّر ممارسات المستخدم واهتماماته بعد إتمام المعاملة

### +3 **انعدام النتائج السلبية**

التفاعل مُصمَّم للحماية من الخسارة، ويتجاوز معايير الجودة الأساسية

### +2 **الرضا الأساسي**

التفاعل يلبّي المعايير المقبولة اجتماعيًا، ويتجاوز مطالب المستخدم المُعلَنة

### +1 **الوعد الأساسي**

التفاعل يلبّي جميع مطالب المستخدم المُعلَنة، دون أي إضافة

### 0 **الرضا المتهكِّم**

التفاعل يفي بوعد أساسي لا يتطلّب سوى قدر ضئيل من الالتزام تجاه إرضاء المستخدم، أو لا يتطلّب أي التزام

### -1 **انعدام الثقة**

تعرَّض المستخدم للضرر أو الاستغلال، أو حصل على منتج/خدمة تحمل دلائل على غياب الالتزام أو على سوء النية

## التقييم ثنائي الاتجاه

يُتيح LBTAS مساءلة متبادلة في الشبكات الرقمية من خلال الاحتفاظ بتصنيفات لكلا الطرفين:

- **المنتجون**: تعريف مقدّمي الخدمة
- **المستهلكون**: تعريف العملاء

يُسهّل هذا النهج التنظيم الذاتي للمجتمع ويُقلّل الحاجة إلى الإشراف المركزي.

## قراءة السمعة

لا يُحسَب متوسط التصنيفات أبدًا. فالسمعة هي عدد التصنيفات المستلَمة عند كل مستوى (من `-1` إلى `+4`) مضافًا إليها المجموع الكلي. والمجموع الكلي مهم بحدّ ذاته: فهو يعكس حجم المعاملات، ويعكس بصورة غير مباشرة مدّة الخدمة. فالتوزيع النظيف على 5,000 تصنيف يمثّل مؤشرًا أقوى من التوزيع نفسه على 5 تصنيفات فقط — وحساب المتوسط كان سيُلغي هذا الفارق بردّ الحالتين إلى الرقم نفسه. (العدد هو عدد التصنيفات؛ أمّا أرقام المعاملات ومدّة الخدمة الدقيقة فتأتي من الـ API الذي يُسجّل طابعًا زمنيًا لكل حدث تصنيف.)

لا يُخفَّف أثر التصنيف `-1` («انعدام الثقة») أبدًا: فأمر `report` يُبرز كل تبادل حصل على تصنيف `-1` واحد أو أكثر داخل قائمة `harm_flagged`، كما يُضيف أمر `list` علامة ضرر إلى أي تبادل يحمل تصنيف `-1`.

## الميزات

- **المنهجية**: مبنية على أُطر التقييم المستخدمة في الفضاء الجوي
- **التقييم ثنائي الاتجاه**: تقييم كلا الطرفين في المعاملات
- **درجة التفصيل**: مقياس من ست درجات مع تعريفات
- **الاعتماديات**: التكامل مع الأنظمة الأخرى
- **دعم قواعد البيانات**: دعم طبقة التخزين الدائم
- **مفتوح المصدر**: تطوير وتخصيص بقيادة المجتمع

## التثبيت

```bash
# Clone the repository
git clone https://github.com/NTARI-OpenCoreLab/Leveson-Based-Trade-Assessment-Scale.git
cd Leveson-Based-Trade-Assessment-Scale

# Make executable (optional)
chmod +x lbtas.py

# Run directly
python3 lbtas.py --help
```

لا يتطلّب أي اعتماديات خارجية. يستخدم مكتبة Python 3 القياسية فقط.

## البداية السريعة

```python
from lbtas import LevesonRatingSystem

# Initialize the rating system
rating_system = LevesonRatingSystem()

# Add an exchange (transaction)
rating_system.add_exchange("transaction_001")

# Add ratings (categories: reliability, usability, performance, support)
rating_system.add_rating(
    exchange_name="transaction_001",
    criterion="reliability",
    rating=3  # No Negative Consequences
)

# Read the distribution (ratings are never averaged)
ratings = rating_system.view_ratings("transaction_001")
print(ratings["reliability"])
# {'distribution': {'-1': 0, '0': 0, '1': 0, '2': 0, '3': 1, '4': 0}, 'total': 1}
```

### واجهة سطر الأوامر

```bash
# Interactive rating
python3 lbtas.py rate --exchange "MyService"

# Programmatic rating
python3 lbtas.py add --exchange "MyService" --criterion reliability --rating 3

# View ratings
python3 lbtas.py view --exchange "MyService"

# Generate report
python3 lbtas.py report

# Export data
python3 lbtas.py export --format json --output ratings.json
```

## التخزين

يستخدم LBTAS التخزين في ملف JSON لحفظ البيانات:

```python
# Initialize with storage file
rating_system = LevesonRatingSystem(storage_file='ratings.json')

# Ratings are saved automatically to the file
rating_system.add_exchange("service_001")
rating_system.add_rating("service_001", "reliability", 3)
```

صيغة ملف التخزين:
```json
{
  "service_001": {
    "reliability": [3, 4, 3],
    "usability": [2, 3],
    "performance": [4],
    "support": [3, 3, 2],
    "_metadata": {
      "created": "2024-09-04T10:30:00",
      "total_ratings": 10
    }
  }
}
```

### فئات التصنيف

الفئات الافتراضية:
- **الموثوقية (Reliability)**: إمكانية الاعتماد والاتساق
- **قابلية الاستخدام (Usability)**: سهولة الاستخدام وتجربة المستخدم
- **الأداء (Performance)**: السرعة والكفاءة
- **الدعم (Support)**: جودة خدمة العملاء

يمكن تعريف فئات مخصّصة أثناء التهيئة.

## البنية

يُنفَّذ LBTAS كوحدة Python واحدة تتضمّن:

1. **الصنف الأساسي**: `LevesonRatingSystem` يُدير التصنيفات والتخزين
2. **الحفظ بصيغة JSON**: تخزين قائم على الملفات مع حفظ تلقائي
3. **واجهة CLI**: أداة سطر أوامر للاستخدام التفاعلي والبرمجي
4. **بلا اعتماديات خارجية**: تستخدم مكتبة Python القياسية فقط

يدعم النظام ما يلي:
- جمع التصنيفات تفاعليًا
- إرسال التصنيفات برمجيًا
- فئات تصنيف مخصّصة
- إنشاء التقارير وتصدير البيانات
